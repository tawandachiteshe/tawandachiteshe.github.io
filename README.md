# tawandachiteshe.github.io

Personal portfolio: one static `index.html` with no build step.

## Deploy (GitHub Pages)

```sh
git init && git add . && git commit -m "Portfolio"
gh repo create tawandachiteshe.github.io --public --source . --push
```

The site will be live at https://tawandachiteshe.github.io within about a minute.
